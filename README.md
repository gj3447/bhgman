# bhgman

12사도 #4 비행기맨의 사도 자료를 보존하는 private persona repository다.
표시·저장소 이름 `bhgman`은 사용자 요청에 따른 이름이고, 원전의 영문 이름
`Airplane Man`과 인격 UID는 `APOSTLE_MODULE.json`에 보존한다.

이 저장소는 공개 기술 저장소 `gj3447/bhgman_tool` 및 공개 안내 저장소
`gj3447/bhgman_essence`와 별개다. 원문은
`sources/SYMPOSIUM/METAHUMOTONIC/BHGMAN/`에 SYMPOSIUM 커밋
`1f2727a0c0d8d9703193bee6406db21d2fd549dd`의 바이트 그대로 들어 있다.

읽는 순서는 [자료 지도](docs/RESEARCH_MAP.md), [무엇인가](docs/WHAT_IS.md),
[다루는 법](docs/HOW_TO.md)이다. 검증은 `python3 cli.py check`를 사용한다.
