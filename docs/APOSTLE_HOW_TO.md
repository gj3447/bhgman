# 공개 자료를 읽는 방법 — Airplane Man essence

이 저장소의 공개 README와 향후 공개된 문서를 존재론적 소개로 읽는다. 실행 가능한 도구 사용법은 [bhgman_tool](https://github.com/gj3447/bhgman_tool)을 확인한다. 이 저장소는 user-paced canonical export를 전제로 하므로, 공개되지 않은 내부 자료를 추정하거나 복제하지 않는다.

1. 먼저 이 저장소가 tool이 아니라 essence layer라는 구분을 읽는다([README](../README.md)).
2. 설치·런타임·Lean·Claude Code skill 같은 공학적 질문은 별도 `bhgman_tool`로 보낸다([README](../README.md)).
3. 공개된 텍스트만 인용하고, user-canonical content의 확장·해석은 원문 상태와 분리한다.
